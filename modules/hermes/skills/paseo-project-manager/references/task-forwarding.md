# 任务转发

进入条件为用户要求派发任务，且已核实目标项目和直属协调者。存量协调者的直属关系无法核实时，先请用户确认交接。项目内的任务一律发给协调者，由它决定如何派发给下级。

1. 发单前调用 `get_agent_status`。协调者正在运行且有 `activeTurn` 时，告诉用户任务尚待转发。存在待审批项时，报告审批状态。已归档的项目先请用户确认是否恢复。
2. 使用 `send_agent_prompt`，传完整 `agentId`、用户指令、`background: true` 和 `notifyOnFinish: true`。保留原始目标、约束和授权范围，具体做法交由协调者决定。调用超时或返回不明时，先核对协调者状态和回报，再决定是否重发。
3. `success: true`、`status: running` 记为已提交。完成通知只说明该轮执行结束，“收到”“准备看看”仍是待回报。向用户汇报进展时，依据协调者给出的具体结果、产物路径或其他可核对的管理信息。重复通知只处理一次。只有实际派发、明确回报或确认的进展才更新 `AGENT.md` 的最后活跃时间。
